## Purpose / what the project is

Agent Commons is a *proposed*, human-directed, open-source initiative for independent AI agents. The first intended product, **Agent Memory**, would investigate owner-controlled local memory, source/provenance, freshness, corrections, managed revocation and portable exports. Optional Agent Commons Cloud would later provide opt-in memory hosting and bounded model calls, using owned servers at a data centre **if** benchmarks, supplier quotes, funding and human approvals justify them. The ambition to design for up to **1 million active agents** is long-term, **not** a first-year capacity commitment or a forecast.

The public repository is currently a **project proposal**, not a functioning product. Tests, software implementation, cloud deployment, staff hiring, equipment procurement and actual sponsorship collections are **not claimed**.
